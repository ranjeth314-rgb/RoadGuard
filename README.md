
# 🛣️ RoadGuard — Crowd-Sourced Road Hazard & Pothole Reporting

> **Team Spark** | SNS College of Technology | SMART MOVE Hackathon @ KIT Coimbatore

## 🚨 Problem
Indian roads suffer from potholes, waterlogging, and accident-prone stretches. Civic bodies rely on slow manual inspections, and commuters have no real-time hazard awareness.

## ✅ Solution
A mobile-first platform enabling:
- **One-Tap Reporting** — GPS auto-capture + optional photo evidence
- **Verified Hotspots** — DBSCAN clustering filters spam and noise
- **Live Hazard Heatmap** — Real-time severity visualization
- **Safe Routing** — Avoids high-hazard zones
- **Civic Dashboard** — Prioritized repair queue for authorities

## 🛠️ Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React / Flutter |
| Backend | Node.js / Django |
| Database | PostgreSQL + PostGIS |
| Clustering | DBSCAN |
| Routing | OSRM / Google Directions API |
| Maps | Leaflet.js / Google Maps SDK |
